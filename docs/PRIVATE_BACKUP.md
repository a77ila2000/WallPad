# 공개 저장소 밖에 보관할 자료

공개 GitHub에 올리지 않습니다. 장치를 초기화하기 **전**에 암호화된 로컬 백업에 보관하고, 복구할 때도 각 장치의 접근 권한을 제한합니다.

- **R6850**: `sysupgrade -b` 설정 백업, `/etc/config/network`, `wireless`, `firewall`, `dropbear`, WireGuard 개인키·피어 구성, SSH 키, `/etc/elevator.env`, `/etc/elevator-call.token`, `/usr/share/elevator/*-request.bin`, 실제 `/etc/init.d/wallpad-adb`, 사용자 지정 핫플러그/서비스 설정. 펌웨어 이미지는 모델·하드웨어 버전과 SHA-256을 대조해 따로 보관합니다.
- **Oracle 서버**: 실제 `config-server.json`, API/ingest 토큰, COMMAX·아파트아이 계정 또는 갱신 세션, 인증서/프록시 설정, systemd 서비스의 운영 환경변수, 필요 시 방문 사진·차량 기록 상태 파일. 세션 파일은 0600 권한으로 둡니다.
- **월패드**: 기존 COMMAX 시스템·앱은 보존하고 월패드 브리지의 설치 APK 해시, 앱 데이터/설정, 야간 벨소리 원본과 15% 파일 및 선택 설정을 개인 백업합니다. 실제 USB 장치 식별자·출입구 주소 매핑은 현장에서 재확인합니다.
- **휴대폰**: 앱 연결 설정, 개인용 연락처/방문객 표기, 알림 접근·마이크 권한, Tasker/Tap, Tap/RegiStar 단축 동작, VPN 프로필을 따로 백업합니다. 잠금 화면 동작은 OS 설정에 좌우됩니다.
- **카메라**: 이 저장소 범위 밖입니다. 카메라 관련 백업과 복구 문서를 별도 프로젝트에 보관합니다.

토큰이나 키가 백업에 없으면 기존 값을 추측하거나 공개 파일에서 복원할 수 없습니다. 새 값을 발급하고 서버·앱·공유기 양쪽 설정을 일치시켜야 합니다.
