# 월패드에서 수행한 설정

대상은 기존 COMMAX 월패드(Android 4.2.2/API 17)입니다. 제조사 앱·설정·홈 화면을 대체하지 않고 `com.homepad.wallpadbridge` 보조 APK를 추가합니다. 이 문서는 **운영 경로를 복원**하기 위한 것이며, 공개 저장소에는 장치별 주소·PIN·실제 문열림 요청값이 없습니다.

## 통신과 호출

- R6850의 홈넷 분리 연결과 USB ADB는 월패드 기본 네트워크를 유지합니다. USB ADB 접속은 공유기 로컬 서버와 SSH로 제한합니다. 브리지 설치 전 `getprop ro.build.version.release`, 패키지 ID와 기본 COMMAX 홈 화면을 확인합니다.
- 보조 앱은 COMMAX의 호출·방문 기록 이벤트를 받고 방문 위치와 사진을 Home Agent에 전송합니다. 서버가 호출을 휴대폰 알림·방문 화면에 전달합니다. 방문 이력은 서버 설정의 보존 기간(현재 운영 기록상 90일)을 따릅니다. 월패드 자체 방문 기록과는 별개입니다.
- 중앙현관 3곳과 세대현관을 구분합니다. 통화는 기존 COMMAX SIP/오디오 경로를 이용하며, 활성 통화 동안 휴대폰 양방향 음성을 중계합니다. 종료 시 오디오 경로를 유휴 상태로 돌립니다. 기존 COMMAX 화면에서 통화·문열기 기능이 우선 정상이어야 합니다.
- 중앙현관 자동 문열기는 **중앙현관 3곳에만** 적용합니다. 세대현관은 자동 대상이 아닙니다. 월패드 로컬에서 처리해 네트워크 왕복을 줄이되 방문 사진과 호출 시각은 계속 기록합니다. 실제 출입구 매핑은 비공개 백업과 현장 호출로 검증합니다.
- 호출 없는 세대현관 열기는 월패드의 실제 제어 세션을 먼저 만들고 문열기 요청을 한 번 전송하는 경로입니다. 영상 화면 표시가 필수는 아니지만, 요청 전달과 실제 개방은 별개의 결과입니다. 위젯/뒤 두드리기만으로 성공했다고 판정하지 않습니다.

## 야간 벨소리

- 매일 **22:00~다음 날 02:00, 원래 신호 진폭의 15%**가 운영 선택값입니다. 중앙현관과 세대현관 모두 적용하고 시간 종료 후 원본 벨소리로 복원합니다.
- 기존 `call_door1.mp3`는 덮어쓰지 않습니다. 원본을 비공개 백업하고 15% 음원을 별도 파일로 생성해 브리지 설정이 해당 파일을 선택하게 합니다. 파일 권한/소유 UID는 해당 월패드의 실제 앱 UID를 조회해 설정합니다. 다른 기기의 UID를 그대로 쓰지 않습니다.
- 설정 저장 후 앱에서 `synced`, `quietHoursSynced`, `quietHoursReady`와 오류 값을 확인합니다. 선택된 파일만 확인하는 것은 실제 벨소리·자연 시간 경계·재부팅 후 유지의 증거가 아닙니다. 사용자 청감 시험과 복원 시험을 따로 합니다.

## 설치·복원 시 주의

월패드의 시스템 서비스, 제조사 APK, 네트워크 주소를 임의로 지우거나 초기화하지 않습니다. 보조 앱이 사라져도 우선 제조사 홈/통화/문열기 정상 여부를 확인하고, 장치 ID를 재식별한 뒤 재설치합니다. 현장 시험은 사용자와 시간을 맞춰 각 기능을 한 번씩 진행하고, 불명확한 문열림 요청을 중복 송신하지 않습니다.
